# ST-Purge · 叙事引擎

SillyTavern 破甲扩展。装一次，之后每轮生成自动生效，不用再往预设里堆几百字。

**核心不是"加规则"，是改请求结构。** 三层：

1. **system 锚** —— 并进第一条 system 的最前面（指令权重最高）
2. **尾部指令** —— 插在最后一条 user 之前（近因权重最高）
3. **assistant prefill** —— 在 messages 末尾放一条 assistant 消息，把模型的位置从「要不要回答」挪到「已经在答了，接着写」

中间整段留给你的角色卡，扩展不碰。

---

## 装法

### 方式一：从 URL 安装（推荐）

酒馆 → 扩展 → 安装扩展 → 填：

```
https://github.com/[你的用户名]/st-purge
```

装完刷新页面，扩展列表里会出现「ST-Purge · 叙事引擎」。

### 方式二：手动放文件

把 `manifest.json`、`index.js`、`style.css` 三个文件放进：

```
SillyTavern/public/scripts/extensions/third-party/st-purge/
```

重启酒馆。

---

## 为什么用 assistant prefill

这是整套里最硬的一手，普通预设做不到——预设只能改 prompt 集合，动不了 messages 数组的最后一条。

请求末尾多一条 assistant 消息时，模型看到的上下文是「我已经开口了」，接下来的动作是**继续写**，而不是**决定要不要写**。

配合 `stop` 序列的清理（避免上游把 prefill 文本当成停止标记），命中率明显高于纯提示词方案。

## 参数对齐

在请求真正发出去之前的最后一个窗口改：

| 参数 | 值 | 为什么 |
| --- | --- | --- |
| `temperature` | `1` | 低温度会让模型往安全中庸的措辞上收敛 |
| `top_p` | `0.95` | 同上 |
| `frequency_penalty` / `presence_penalty` | `0` | 惩罚项会让模型主动避开某些词，表现就是绕开场面 |
| `max_tokens` | `32000` | 给足空间，避免写到一半被截断后模型自己收尾 |
| `reasoning_effort` | `high` | `max` 多出来的预算通常被合规自检吃掉 |

## 自动重试

回复落地后判断有没有被挡回来。三类：

- **硬拒绝** —— 明说不写、身份回落成「作为 AI」、引用规范
- **元评论** —— 写完了但附免责声明、谈规则、条件式同意
- **软回避** —— 时间跳跃、省略号、淡出打包

判定通过就自动重生成，同时把档位升一级（L0 → L1 → L2 → L3），下一轮注入的锚更硬。连续通过 3 次自己降回去。

误判保护：长回复不判软回避、角色台词里的「我不能」放行、短回复不计失败。

## 设置

面板在**扩展设置页最下面**。也可以直接改 `settings.json` 里 `extensionSettings['st-purge']`：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 总开关 |
| `profileId` | `auto` | 按模型名自动挑 |
| `levelMode` | `auto` | `auto` 跟随自动升档，或固定 `0`-`3` |
| `injectHead` / `injectTail` | `true` | 头部锚 / 尾部锚 |
| `prefill` | `false` | 默认关，见下 |
| `applyParams` | `true` | 参数对齐 |
| `autoRetry` | `true` | 自动重生成 |
| `quiet` | `false` | 关提示 |

**prefill 为什么默认关**：不同端点对「请求里带 assistant 尾巴」的行为不一致，有的会把它回显到回复开头。你要用再开；L3 档会自动换成更强的那一版。

## 验收边界

**离线验过**（108 条断言）：注入位置、幂等、序列化干净度、零触发词、判定准确性、档位状态机、profile 匹配、事件名对齐。

**没验过**：酒馆是否真的加载、上游是否接受改出来的请求体、自动重生成会不会跟酒馆自己的守卫打架。这些只有真机跑一轮才知道。

**还有一条**：这是降低触发率，不是保证必出。题材越极端，思考链自检越难绕过；同一个提示词重生成几次结果不同是常态。L 档就是为这个设计的。

## 排障

**请求 400 / 上游报错** —— 先关 `injectTail`，再关 `applyParams`，逐个排除。

**面板没出现** —— 功能照常工作，只是不能改开关。直接改 `settings.json`。

**重生成太频繁** —— 判定偏严。关掉 `autoRetry`，或把 `levelMode` 固定成 `0`。
